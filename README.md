# Thapelo Duma | Personal Bio

Welcome to the source for my personal website. It introduces my work in DevOps and data platforms, my education, technical skills, and interests outside work. The site is a single responsive page built with plain HTML, CSS, and JavaScript.

## Explore the site

Use the navigation to jump between About, Work, Education, Skills, Outside Work, and Connect. The Connect section has links to my LinkedIn, GitHub, and email.

## Download and run locally

1. On GitHub, select **Code → Download ZIP**.
2. Extract the ZIP to a folder on your computer.
3. Open a terminal in the extracted folder containing `index.html`.
4. Run:

   ```bash
   python3 -m http.server 8000
   ```

5. Open [http://localhost:8000](http://localhost:8000) in your browser. Press `Ctrl+C` in the terminal to stop the server.

There is nothing to install or build. For a quick look, you can also open `index.html` directly in a browser; serving it locally lets the copy-link button work as intended.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page content and navigation |
| `styles.css` | Layout, colours, and responsive styling |
| `script.js` | Copy-link interaction and footer year |

All site assets use relative paths, so the extracted files work together without extra configuration.
